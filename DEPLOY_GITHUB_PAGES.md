# 🚀 Deploy no GitHub Pages (GRÁTIS)

## Passo a Passo

### 1. Fazer Push do Código

```bash
git add .
git commit -m "feat: configurar GitHub Pages"
git push origin main
```

### 2. Ativar GitHub Pages

1. Acesse seu repositório no GitHub
2. Vá em **Settings** → **Pages**
3. Em **Source**, selecione: **GitHub Actions**
4. Pronto! O deploy será automático

### 3. Acessar o Site

Após o deploy (1-2 minutos), acesse:
```
https://SEU-USUARIO.github.io/essencial-fidelidade/
```

## ✅ Vantagens

- 🆓 **100% Gratuito**
- 🔒 **HTTPS automático**
- 🚀 **Deploy automático** (push = deploy)
- 📱 **PWA funcional**
- ☁️ **Supabase já configurado**

## 🔄 Atualizações

Qualquer push na branch `main` faz deploy automático!

```bash
git add .
git commit -m "sua mensagem"
git push
```

## 📝 Nota

Se o repositório tiver outro nome, a URL será:
```
https://SEU-USUARIO.github.io/NOME-DO-REPO/
```
